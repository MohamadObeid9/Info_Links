About Info Links

The problem

Every semester, the same question in random group chats: "Does anyone have the link for X?" No central place. No organization. Just noise.

How it started

In February 2025 I started a Telegram channel — Info Links — manually organizing course links, Drive folders, Classroom pages, and Telegram groups by program, year, and semester.

What began as one person with a simple idea grew to 300+ students in under a year. The problem was real — and bigger than I thought.

What it is today

Info Links is a free hub for 50+ courses at Le CNAM Lebanon — from foundational subjects through License and partial Master's in Computer Science. Search by name or code, filter by program/year/semester, and find Drive, Classroom, Telegram, and other links in one place.

Behind the scenes, the platform now runs on a Go REST API with the same Postgres database — same product students already use, with engineering that can grow with the community.

Free, always

If I was a broke student looking for course materials, I wouldn't pay. So this stays free. It exists because of the community — and it belongs to the community.
