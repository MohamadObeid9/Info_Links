# Security Policy

## Reporting a vulnerability

If you discover a security issue in Info Links, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Email the maintainer via the contact on [GitHub](https://github.com/MohamadObeid9/Info_Links) or reach out on [Telegram](https://t.me/Info_Links9).
3. Include a description of the issue, steps to reproduce, and potential impact.

We will acknowledge receipt and work on a fix. Please allow reasonable time before public disclosure.

## Scope

- The Go API and admin authentication flows
- Rate limiting, CORS, and security headers
- Data access via the repository layer

Out of scope: third-party services (Supabase, Render) — report those to the respective providers.
